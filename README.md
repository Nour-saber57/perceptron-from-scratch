# Perceptron From Scratch

A perceptron implemented from scratch in pure Python/NumPy — 
no ML libraries used for the model itself.

## What's implemented manually
- Sigmoid activation function
- Forward pass
- Gradient descent weight updates
- Bias updates
- Accuracy evaluation

## Dataset
Breast Cancer dataset (sklearn) — binary classification

## Why this matters
Most people use sklearn or Keras as a black box. 
This project demonstrates understanding of what happens 
under the hood of a neural network.
